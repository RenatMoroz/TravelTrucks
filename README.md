# 🚐 TravelTrucks - pet project

A web application for searching and renting campers with filtering by location, vehicle type, and equipment.

🔑 Key Features

- Camper catalog browsing
- Filtering by:
- location
- camper type
- equipment (AC, kitchen, TV, bathroom, automatic transmission)
- Incremental loading (Load more)
- Camper detail page
- Favorites functionality
- Booking form
- Responsive layout

## 🧰 Tech Stack

Next.js | React | TypeScript | Zustand | CSS Modules | Axios | MockAPI
